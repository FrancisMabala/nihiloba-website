# Mon espace navigation — 22 October 2026

Approved design: forest-green and cream marketplace header with outlined basket, language and account controls; basket only in SHIDA. Desktop personal sidebar has Home, Orders, Requests, Messages, Receipts, grouped Manage my activities, then Account settings. Phone uses Home / Messages / Manage / Menu bottom navigation, with a native modal containing every destination. Business management links are grouped, with existing Services capability discovery preserved. Existing links still perform independent authorization.

Account dropdown contains Mon espace, Account settings, Change account and Sign out. Shared seller headers use the same compact personal-account destinations and preserve unsaved-work navigation checks. The organization dashboard remains a separate authenticated destination; no personal-to-organization authority is inferred.

The mockup used illustrative data. Production shows actual latest restaurant and Wenze orders from existing authenticated read endpoints (up to five from each source), grouped by marketplace, with their existing order-progress labels. Fulfillment status never implies payment. No invented unread count, reservation or service activity is shown. Messages and requests open their established conversation pages; receipts open their canonical invoice/order destinations. Settings shows the current account and lets users change language; account switching/sign-out remain in the existing account menu. EN/FR/LN/SW copy included; marketplaces available only in EN/FR retain their established fallback.

Private state is memory-only, remounted on account binding changes, aborted on unmount, and cleared before session revalidation. Account switching, sign-out, focus, online and cross-tab notifications revalidate identity. The account page has no-store/noindex response headers. API contracts, WhatsApp login/code flow, provider capability checks and sign-out are unchanged. No database migration, production data mutation, new dependency or secret is needed.

Validation and deployment results are recorded in the final release report. Browser fixtures use synthetic accounts/orders and do not send WhatsApp messages.
